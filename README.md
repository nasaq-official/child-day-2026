# عالم الطفل — اليوم العالمي للطفل ٢٠٢٦

موقع عربي تفاعلي للابتدائية الثانية بالقاعدة الجوية.

- مديرة المدرسة: سميرة نشاء العصيمي
- رائدة النشاط: افراح الاسمري
- فترة الفعالية المخططة: ١٧–١٩ نوفمبر ٢٠٢٦

## التشغيل

نزّل الملفات معًا وافتح `index.html` في متصفح حديث. لا يحتاج الموقع إلى تثبيت مكتبات أو خدمة خلفية.

## المحتويات

حقوق الطفل، إرشادات السلامة، اختبار تفاعلي، لوحة رسم مع حفظ الصورة، ركن الأسرة، شهادة مشاركة قابلة للطباعة بعد إكمال الاختبار، وتقييم يمكن تصديره بصيغة CSV ونموذج تقرير نصي.

## البيانات

التقييمات تُحفظ محليًا في متصفح الجهاز فقط، ولا تُرسل إلى المدرسة. الأرقام لا تمثل جميع زوار الموقع أو عدد الحضور الفعلي. اسم الشهادة لا يُحفظ. التقرير نموذج يُستكمل بعد تنفيذ الأنشطة فعليًا. الشهادة إلكترونية للنشاط ولا تتضمن توقيعًا رسميًا.

## الملفات

- `index.html`: الصفحة والمحتوى.
- `style.css`: التصميم المتجاوب والطباعة.
- `script.js`: التفاعلات والحفظ المحلي والتصدير.
- `hero.png`: التصميم المقدم للمناسبة.

فُحصت سلامة JavaScript بواسطة `node --check script.js`؛ لم يُجر اختبار مرئي كامل للمتصفح.
